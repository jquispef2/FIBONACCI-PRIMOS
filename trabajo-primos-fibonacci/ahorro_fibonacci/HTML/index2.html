El Problema

Ahorrar sin esfuerzo extra,
crecer de forma natural

La mayoría de las personas abandona su plan de ahorro porque los saltos bruscos de cuota desmotivan. La naturaleza resolvió este problema hace millones de años: los girasoles, los caracoles, los árboles crecen siguiendo la sucesión de Fibonacci — cada etapa es la suma de las dos anteriores. Pequeño al principio, extraordinario al final.

Este simulador aplica ese mismo patrón a tu bolsillo: defines cuántos meses quieres ahorrar y nosotros calculamos cuánto depositar cada mes, cuánto acumulas y cómo crece tu dinero mes a mes.

El Algoritmo

Cómo funciona Fibonacci

01

Inicio

El mes 1 y el mes 2 siempre son Bs. 1 — el punto de partida.

→
02

Suma

Cada mes siguiente = mes anterior + el mes antes de ese. Ejemplo: mes 3 = 1+1 = 2.

→
03

Acumulado

Se suma cada depósito al total anterior y se muestra el ahorro acumulado.

let a = 1, b = 1, c;
for (let i = 3; i <= meses; i++) {
  c = a + b;   // siguiente Fibonacci
  a = b;
  b = c;
}

Conclusión

Pequeños pasos,
grandes resultados

La sucesión de Fibonacci no es solo un patrón matemático — es la forma en que la naturaleza construye cosas grandes desde cosas pequeñas. Al aplicarla al ahorro, evitamos el choque de cuotas fijas altas y permitimos que el hábito crezca de forma orgánica. Con tan solo Bs. 5 al inicio, en 12 meses puedes acumular más de Bs. 700 siguiendo este plan.
