Serie de Fibonacci

Una secuencia donde cada número es la suma de los dos anteriores: 0, 1, 1, 2, 3, 5, 8, 13… Aparece en la naturaleza: girasoles, caracoles, ramas de árboles.

π

Números Primos

Solo divisibles por 1 y sí mismos: 2, 3, 5, 7, 11, 13… Son la base de la criptografía moderna y los protocolos de seguridad.

✦

La Intersección

Algunos términos de Fibonacci son también primos: 2, 3, 5, 13, 89, 233… Estos números son matemáticamente excepcionales — llamados Fibonacci Primos.

Algoritmo

¿Cómo funciona?

  1. 01
    Generar Fibonacci
    Usando dos variables a y b, se calcula cada término con un ciclo: c = a + b, luego a = b, b = c.
  2. 02
    Verificar Primos
    Para cada número de Fibonacci, se cuenta cuántos divisores tiene. Si exactamente 2 divisores → es primo.
  3. 03
    Filtrar y mostrar
    Solo los términos que cumplen ambas condiciones se destacan como "Fibonacci Primos" en el resultado.

function esPrimo(n) {
  if (n < 2) return false;
  for (let i = 2; i <= n; i++) {
    if (n % i === 0 && i !== n)
      return false;
  }
  return true;
}

let a = 0, b = 1, c;
for (let i = 0; i < n; i++) {
  if (esPrimo(a))
    primos.push(a);
  c = a + b;
  a = b; b = c;
}

Conclusión
"La matemática no miente; quizá se disfrace de realidad o de abstracción, pero siempre revela verdades inesperadas."

La combinación de Fibonacci y números primos nos muestra que dentro del orden natural hay elementos únicos e irrepetibles. Los Fibonacci Primos no solo son curiosidades matemáticas: representan la base de algoritmos de hash, generadores pseudoaleatorios y protocolos criptográficos modernos.

Entender estas intersecciones entre dos de los conceptos más fundamentales de las matemáticas nos da una visión más profunda de la estructura del universo numérico.
