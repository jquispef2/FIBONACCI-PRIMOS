ALGORITMO

¿Cómo funciona el cifrado?

01

Prime-Shift

Cada carácter se desplaza en el código ASCII sumando el valor primo de la clave. Para descifrar, se resta la misma clave.

cifrado = char.charCodeAt(0) + clave
descifrado = char.charCodeAt(0) − clave
02

Prime-Mult

El código ASCII se multiplica por la clave primo y se aplica módulo 256. Se usa el inverso modular para descifrar.

cifrado = (charCode × clave) % 256
descifrado = (cifrado × inverso) % 256
03

Prime-XOR

Operación XOR bit a bit entre el código del carácter y la clave. Aplicar XOR dos veces restaura el original.

cifrado = charCode XOR clave
descifrado = cifrado XOR clave

¿Cómo ayuda la matemática a la seguridad?

Los números primos tienen una propiedad única: son irreductibles. No pueden descomponerse en factores menores. Esta característica hace que los algoritmos basados en primos sean extremadamente difíciles de romper sin conocer la clave original.

En la práctica, RSA usa primos de 1024 a 4096 bits. Con claves de este tamaño, factorizar el producto tomaría más tiempo que la edad del universo con hardware actual. Los números primos son, literalmente, la piedra angular de la seguridad digital.
